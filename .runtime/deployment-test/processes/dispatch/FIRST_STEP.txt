DISPATCH - FIRST STEPS
======================

From the directory that contains "processes":

1. Enter the process:

   cd processes/dispatch

2. Create the local environment file:

   Linux/macOS:
   cp .env.detail .env

   PowerShell:
   Copy-Item .env.detail .env

3. Complete SQL_CONNECTION_STRING_DISPATCH in .env.
   Do not commit or package the real .env file.

4. Review the source catalog in:

   src/ada/processes/dispatch/catalog/definitions.py
   src/ada/processes/dispatch/catalog/tables/

   The packaged catalog contains the current ADA Dispatch sources migrated from the validated
   previous implementation. Update only a concrete source definition if the real SQL schema has
   changed. Do not modify the generic Dispatch engine for source-specific schema changes.

5. Create/synchronize the locked Python environment:

   uv sync --python 3.14.2 --frozen

   Do not run "uv lock". The transport bundle already includes its certified uv.lock.
   Do not use pip.

6. Validate one source iteration manually when appropriate:

   uv run --frozen ada-dispatch --run-once

   Dispatch processes one planned source per runtime iteration. Therefore --run-once validates
   only the first pending source, not the entire execution plan.

7. Run the complete 10-minute execution normally:

   uv run --frozen ada-dispatch

NOTES
-----
- Dispatch captures SQL table change markers once at the start of each execution.
- Each source advances its own producer state independently after successful dataset publication.
- Pending sources are ordered by last successful synchronization so continuously changing tables do
  not starve older pending sources.
- Shift-window sources read the current and previous Mine ShiftId.
- SQL extraction uses mssql-python batches and converts directly to PyArrow; Pandas is not used.
- tiempos_mlp exposes source_last_update from MAX(moment) of the materialized data window.
- SQL connection/query retries are controlled by DISPATCH_SQL_RETRY_ATTEMPTS and
  DISPATCH_SQL_RETRY_DELAY_SECONDS.
- If the process loses its Atlanticus lease, runtime requests a controlled stop.
