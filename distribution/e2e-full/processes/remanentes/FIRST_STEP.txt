REMANENTES - FIRST STEPS
========================

From the directory that contains "processes":

1. Enter the process:
   cd processes/remanentes

2. Create the local environment file:
   cp .env.detail .env

3. Configure the Remanentes Storage connection string and container in .env.
   Do not commit or package the real .env file.

4. Create/synchronize the locked Python environment:
   uv sync --python 3.14.2 --frozen
   Do not use pip.

5. VALIDATE ONE SCHEDULED EXECUTION
-----------------------------------
   uv run --frozen ada-remanentes

   Remanentes is a run-once job. One process execution scans stocks, extraibles and no_extraibles
   once and exits. The platform schedule is responsible for starting the next execution.

6. PLATFORM SCHEDULE
--------------------
   config.detail.json provides the deployment reference for an execution every 10 minutes.
   Copy/adapt it as config.json in the consumer repository before deployment.

NOTES
-----
- Remanentes uses one Storage connection string and one container for all three streams.
- Streams: stocks, extraibles and no_extraibles.
- Source discovery resumes from the persisted cursor and scans required America/Santiago day partitions.
- Source filename timestamps are interpreted in America/Santiago and converted to UTC.
- State remains under .runtime/state/producers/remanentes.json.
